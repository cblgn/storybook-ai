# Security policy

## Supported versions

Storybook AI is a young, pre-1.0 project. Security fixes target the current `main`
branch. There are no maintained older release lines; update to the latest main
revision before reporting an issue. The application is intended for local use.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/cblgn/storybook-ai/security/advisories/new).
Do **not** disclose vulnerabilities, credentials, exploit details or children's
personal information in a public issue or pull request.

Include the affected revision, a minimal reproduction, expected impact and any
safe mitigation. Use synthetic data and redact all credentials. If a credential
has been exposed, revoke or rotate it promptly; deleting its visible text is not
sufficient.

The solo maintainer will acknowledge and triage reports as availability permits,
coordinate fixes privately, and publish an advisory when appropriate. There is no
guaranteed response SLA or bounty program.
